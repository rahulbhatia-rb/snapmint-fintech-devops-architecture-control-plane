# SEV-1 infrastructure runbook

1. Declare incident / owner.
2. Establish customer impact.
3. Freeze unrelated changes.
4. Identify latest infrastructure / release change.
5. Mitigate using the smallest safe action.
6. Roll back or fail over if required.
7. Track timeline and decisions.
8. Restore normal service.
9. Run blameless postmortem.
10. Convert recurrence risks into owned corrective actions.
